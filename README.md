# Porto Seguro’s Safe Driver Prediction

## О проекте
Решение соревнования с Kaggle по предсказанию вероятности подачи страхового иска водителем в следующем году. В проекте реализован полный пайплайн: от EDA и генерации признаков до взвешенного блендинга трех SOTA-алгоритмов градиентного бустинга.

**Датасет:** https://www.kaggle.com/c/porto-seguro-safe-driver-prediction

**Оптимизируемая метрика:** Normalized Gini Coefficient.

**Стек технологий:** Python, Pandas, NumPy, Scikit-learn, LightGBM, XGBoost, CatBoost, SciPy, Matplotlib/Seaborn.
---

## 1. EDA и Feature Engineering

* **Обработка пропусков:** Все значения `-1` были переведены в `NaN`, чтобы градиентные бустинги могли обрабатывать их встроенными алгоритмами.
* **Генерация `missing_count`:** Добавлен новый признак — количество пропущенных значений в строке. Метрика показала рост.
* **Удаление шумовых признаков:** Матрица корреляций показала, что весь блок признаков `ps_calc_` имеет нулевую связь с целевой переменной. 

## 2. Что не сработало

* **Гипотеза:** Создать полиномиальные признаки через перемножение сильно коррелирующих столбцов.
* **Результат:** CV Gini снизился с 0.27777 до 0.26119.
* **Вывод:** ручное перемножение только поспособствовало переобучению моделей.

## 3. Архитектура и Валидация

Для оценки моделей использовалась строгая кросс-валидация **StratifiedKFold на 5 фолдов**. 
**Базовые модели:**
Для обеспечения разнообразия были выбраны три алгоритма с разной логикой построения деревьев:
1. **LightGBM**
2. **XGBoost**
3. **CatBoost**

## 4. Блендинг

Вместо классического тяжелого стекинга, который мог легко переобучиться на наших предсказаниях, был использован **Weighted Blending**. 

Веса для OOF-предсказаний были математически подобраны через оптимизатор `scipy.optimize.minimize`
